## Pendahuluan

Secret yang sudah di-push sudah cukup publik untuk menjadi masalah. Catatan ini
memakai [Gitleaks](https://github.com/gitleaks/gitleaks), pemindai secret
berbasis Go, sebagai jaring pengaman singkat: temukan kredensial yang tertulis
di riwayat, periksa staged changes secara lokal, lalu blokir push yang buruk
di CI.

Panduan ini memakai rilis `v8.30.1`. Gitleaks kini feature-complete, jadi
perlakukan sebagai perkakas yang stabil, bukan platform untuk dibangun di
atasnya.

## Instalasi

### Homebrew

```bash
brew install gitleaks
```

### Docker

Jalankan pindai tanpa menginstal apa pun:

```bash
docker pull ghcr.io/gitleaks/gitleaks:latest
```

```bash
docker run -v "$(pwd)":/path ghcr.io/gitleaks/gitleaks:latest git /path
```

Volume mount itu penting: container tidak bisa memindai riwayat yang tidak
bisa dilihatnya.

### Go

Repo-nya pindah, tetapi module path Go tidak berubah:

```bash
go install github.com/zricethezav/gitleaks/v8@v8.30.1
```

## Penggunaan

### Pindai riwayat commit

```bash
gitleaks git
```

```bash
gitleaks git -v path/to/repo
```

```bash
gitleaks git --redact
```

`gitleaks git` hanya membaca riwayat yang sudah di-commit. Ia tidak melihat
perubahan yang belum di-commit.

### Pindai staged dan unstaged changes

```bash
gitleaks git --pre-commit --staged
```

`--pre-commit` melihat perubahan unstaged. `--staged` melihat staged changes.
Pakai keduanya sebelum commit.

### Pindai direktori atau stdin

```bash
gitleaks dir -v ./some/path
```

```bash
cat config.yaml | gitleaks stdin
```

### Buat laporan agar CI gagal

```bash
gitleaks git --report-format sarif --report-path results.sarif --redact
```

Exit `1` berarti ada kebocoran, sehingga langkah CI gagal tanpa skrip tambahan.

## Cegah push yang buruk

### Hook pre-commit lokal

Pakai framework [pre-commit](https://pre-commit.com/) dan tambah berkas ini:

```yaml
repos:
  - repo: https://github.com/gitleaks/gitleaks
    rev: v8.30.1
    hooks:
      - id: gitleaks
```

Lalu instal:

```bash
pre-commit install
```

### Gerbang CI minimal

Baris terpenting adalah `fetch-depth: 0`; shallow clone hampir tidak
menyisakan riwayat untuk dipindai:

```yaml
- uses: actions/checkout@v6
  with:
    fetch-depth: 0
- name: Scan for secrets
  run: |
    docker run -v "$PWD":/repo ghcr.io/gitleaks/gitleaks:latest \
      git /repo --report-format sarif --report-path /repo/results.sarif --redact
```
